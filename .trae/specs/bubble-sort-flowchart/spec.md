# 冒泡排序流程图 - 产品需求文档

## Overview
- **Summary**: 绘制一张标准冒泡排序（Bubble Sort）算法流程图，以 PNG 图片形式交付。
- **Purpose**: 帮助 C 语言初学者直观理解冒泡排序的双重循环、比较与交换逻辑。
- **Target Users**: 学习 C 语言/数据结构的学生（当前工作区为 C 语言练习目录）。

## Goals
- 用标准流程图符号完整、准确地表达冒泡排序算法流程。
- 生成一张可直接查看、可插入文档的清晰 PNG 图片。
- 中文标注无乱码，布局整洁。

## Non-Goals
- 不编写冒泡排序的可执行 C 代码（仅流程图）。
- 不制作动画演示或交互式页面。
- 不包含复杂度分析等扩展教学内容。

## Background & Context
- 工作区 `d:\vscode\c_practice` 为 C 语言练习目录。
- 环境已安装 Python 3.13 与 Pillow；Windows 系统自带微软雅黑字体可用于中文绘制。
- 采用 Pillow 直接绘制图形（矩形/菱形/圆角矩形/箭头），无需额外安装 Graphviz 等依赖。

## Functional Requirements
- **FR-1**: 生成文件 `d:\vscode\c_practice\冒泡排序流程图.png`，可正常打开查看。
- **FR-2**: 流程图使用标准符号：圆角矩形表示开始/结束，矩形表示处理步骤，菱形表示条件判断，带箭头线段表示控制流向。
- **FR-3**: 流程图包含完整冒泡排序逻辑节点：
  1. 开始；
  2. 输入数组 a 及长度 n；
  3. 外层循环初始化 i=0；
  4. 判断 `i < n-1`，否则结束（输出排序后数组）；
  5. 内层循环初始化 j=0；
  6. 判断 `j < n-1-i`，否则执行 i=i+1 并回到外层判断；
  7. 判断 `a[j] > a[j+1]`，成立则交换两者；
  8. j=j+1 并回到内层判断；
  9. 结束。
- **FR-4**: 所有判断分支标注"是/否"，循环回边箭头方向正确、走向无交叉歧义。

## Non-Functional Requirements
- **NFR-1**: 图片以 2 倍像素密度渲染，文字与线条清晰无锯齿。
- **NFR-2**: 中文使用微软雅黑字体，不出现方框/乱码。
- **NFR-3**: 配色统一（深蓝边框、浅色填充、橙色强调判断分支），视觉整洁。

## Constraints
- **Technical**: 仅使用已安装的 Python + Pillow；字体使用 `C:\Windows\Fonts\msyh.ttc`。
- **Business**: 产物保存在工作区目录内。
- **Dependencies**: Pillow、Windows 微软雅黑字体。

## Assumptions
- 采用升序排序（`a[j] > a[j+1]` 时交换），这是冒泡排序最常见教学版本。
- 用户期望的是静态图片 PNG；如后续需要 HTML/SVG 版本可另行提出。

## Acceptance Criteria

### AC-1: 图片文件成功生成且可打开
- **Type**: `rule`
- **Given**: 运行绘制脚本
- **When**: 脚本执行完成
- **Then**: 工作区存在 `冒泡排序流程图.png`，Pillow 能重新打开且尺寸非零
- **Pass Condition**: 文件存在，且 `Image.open()` 成功、宽高均 > 0
- **Evidence**: 脚本输出 + 程序重新读取校验 + 人工目视图片

### AC-2: 流程图逻辑节点完整
- **Type**: `rule`
- **Given**: 查看生成的流程图
- **When**: 逐节点比对 FR-3
- **Then**: 9 类逻辑节点（开始、输入、i=0、i<n-1 判断、j=0、j<n-1-i 判断、a[j]>a[j+1] 判断、交换、j=j+1、i=i+1、结束）全部存在且文字正确
- **Pass Condition**: 每个节点都能在图中找到且标注文字一致
- **Evidence**: 人工目视核对 + 渲染图截图

### AC-3: 控制流正确性
- **Type**: `rubric`
- **Dimension**: 算法逻辑表达准确度
- **Scale**: 1-5
- **Anchors**: 1 = 分支或循环方向错误；3 = 主逻辑正确但个别回边/标签不清晰；5 = 所有判断分支、是/否标签、两层循环回边均准确无歧义
- **Pass Threshold**: >= 4
- **Evidence**: 人工目视箭头走向与文字标签

### AC-4: 可读性与规范性
- **Type**: `rubric`
- **Dimension**: 图形美观与规范程度
- **Scale**: 1-5
- **Anchors**: 1 = 符号混用、文字乱码、箭头交叉混乱；3 = 内容可辨但排版粗糙；5 = 标准符号、对齐整齐、中文清晰、箭头不交叉
- **Pass Threshold**: >= 4
- **Evidence**: 人工目视整体布局、字体、配色
